# Overleaf report package

The Overleaf-ready source is `assignment4_report.tex`. Its six figures are in `figures/` and are copied from the experiment outputs.

Upload `assignment4_overleaf.zip` to Overleaf as a new project, or upload `assignment4_report.tex` and the complete `figures/` folder together. The document uses standard Overleaf packages and compiles with pdfLaTeX.
